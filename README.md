# Explorease – AI Trip Planner 🌍✈️

Explorease is an AI-powered travel planning web application that helps users search, compare, and plan trips by integrating real-time flight and hotel APIs with smart recommendations and an interactive user interface. The platform aims to simplify travel planning by providing personalized and cost-effective travel options in one place.

---

## 🚀 Features

- AI-based trip planning and recommendations  
- Real-time flight search and comparison  
- Hotel price comparison using third-party APIs  
- Smart filtering and sorting options  
- Responsive and user-friendly UI  
- Secure API integration  
- Fast and optimized data fetching
