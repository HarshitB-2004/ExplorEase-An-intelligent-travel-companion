# Explorease – AI Trip Planner 🌍✈️

Explorease is an AI-powered travel planning web application that helps users search, compare, and plan trips by integrating real-time flight and hotel APIs with smart recommendations and an interactive user interface. The platform aims to simplify travel planning by providing personalized and cost-effective travel options in one place.

---

## 🚀 Features

- AI-based trip planning and recommendations  
- Real-time flight search and comparison  
- Hotel price comparison using third-party APIs  
- Smart filtering and sorting options  
- Responsive and user-friendly UI  
- Secure API integration  
- Fast and optimized data fetching

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository

git clone https://github.com/your-username/Explorease-AI-Trip-Planner.git


### 2️⃣ Navigate to Project Folder

### 3️⃣ Install Dependencies

For frontend:

npm install


For backend:

cd backend
npm install

### 4️⃣ Environment Variables Setup

Create a `.env` file inside the backend folder and add:

 GEMINI_API_KEY=
 FLIGHT_API_KEY=
 MONGO_URI=
 JWT_SECRET=
 AMADEUS_CLIENT_ID=
 AMADEUS_CLIENT_SECRET=
 OPENWEATHER_API_KEY=
 PEXELS_API_KEY=
 VISUALCROSSING_API_KEY=
 HOTELBEDS_API_SECRET=
 HOTELBEDS_API_KEY=
 GOOGLE_API_KEY=
 ExchangeRate_API_KEY=


### 5️⃣ Run the Project

Start backend server:

node server.js 

Start frontend:

npm run dev

## 📌 How Explorease Works

1. User enters source, destination, and travel dates  
2. System fetches real-time flight and hotel data  
3. AI module analyzes preferences and budget  
4. Best travel options are displayed  
5. User can compare prices and plan trips easily

6. ## 🧠 AI Integration

Explorease uses AI-based logic to:

- Suggest optimal travel routes  
- Recommend budget-friendly options  
- Improve user experience through smart filtering  
- Provide personalized travel suggestions
